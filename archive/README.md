# Archived and supplementary experiments

These files are retained to preserve research history, but are **not presented as the verified final implementation** of the KASA Spring 2026 study.

- `initial_array_comparison.ipynb`: earlier array and MUSIC comparisons.
- `early_linear_music.py`: exploratory linear array simulation with different source settings.
- `ocean_simulation/`: environmental configuration files for separate propagation experiments; not used in the indoor DOA comparisons reported in the paper.
- `editor_settings/`: previously tracked VS Code settings.

For the paper-related implementation, start with `../src/doa_az_guided_planar.py`, `../notebooks/`, and `../docs/experiment_mapping.md`.
